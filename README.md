# OIBSIP_DataScience_Task5

## Sales Prediction

### Objective

To predict future sales based on advertising expenditure and historical sales data.

### Dataset

The dataset contains:
- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget
- Sales Data

### Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

### Steps Performed

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Sales Forecasting

### Results

The model successfully predicted future sales trends.

### Conclusion

Sales prediction helps businesses optimize marketing strategies and improve revenue planning.
